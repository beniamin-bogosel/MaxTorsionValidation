# Original supplied FreeFEM programs

This directory contains the original programs supplied by the researcher:

- `PolygonSplitFast.edp`
- `PolygonSplitRescaled.edp`
- `PolygonSplitRescaled_NEW.edp`
- `PolygonSplitRescaled_NEW2.edp`

They are retained as supplied for provenance and comparison. The maintained
certificate workflow and its reproduction instructions are in
[MaxTorsionValidation](../MaxTorsionValidation/README.md).

Authorship and license information for these original programs should be
supplied by their owner. The repository organization does not assign new
license terms to them.
